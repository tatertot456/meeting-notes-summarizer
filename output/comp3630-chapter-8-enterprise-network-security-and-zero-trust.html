CIA Triad & Incident Response

▶

Confidentiality

Ensures only authorized parties can read data. Enforced via encryption, ACLs, and need-to-know access controls.

Integrity

Guarantees data has not been tampered with. Enforced via hashing (SHA-256), digital signatures, and audit logs.

Availability

Ensures systems remain accessible to authorized users. Achieved through redundancy, failover, and DDoS mitigation.

Incident Response Loop:

  • Prevent: Patch management, firewall rules, user training.
  • Detect: SIEM alerting, IDS signatures, anomaly detection.
  • Respond: Isolate endpoints, block IPs, escalate to IR team.
  • Recover: Restore from clean backups, conduct post-mortem, update controls.

Physical Security & Social Engineering

▶

Physical Controls

Badge readers, mantraps, security cameras, locked server rooms, and cable locks enforce physical asset protection.

Social Engineering

Attacks that manipulate people rather than systems. Examples: phishing emails, pretexting calls, tailgating into secured areas.

Phishing Variants

Spear Phishing targets specific individuals. Whaling targets executives. Vishing uses voice calls.

Defense

Security awareness training, simulated phishing campaigns, and strict visitor escort policies are the primary countermeasures.

IDS & IPS — Detection vs. Prevention

▶

NIPS (Inline — Active)

Sits directly in the traffic path. Drops malicious packets in real time before they reach the target host.

NIDS (Out-of-Band — Passive)

Receives a copy of traffic via a SPAN/mirror port. Generates alerts but does NOT block traffic — zero impact on latency.

HIDS (Host-Based)

Runs as an agent directly on endpoint servers. Monitors local system files, registry changes, and process logs for tampering.

Detection Methods

Signature-Based: Matches known attack patterns. Behavioral/Anomaly: Flags deviations from a learned traffic baseline.

MFA Factor Categories:

  • Something You Know: Password, PIN, security question.
  • Something You Have: Hardware token, authenticator app, smart card.
  • Something You Are: Fingerprint, facial recognition, retina scan.

Key Rule: Two passwords is NOT MFA. MFA requires 2+ factors from DISTINCT categories. A password plus a one-time SMS code qualifies; two passwords do not.

Single Sign-On & Security Policies

▶

SSO allows a user to authenticate once and gain access to multiple systems without re-entering credentials. Kerberos tickets and SAML assertions are common SSO mechanisms.

Security Policy Framework:

  • Governance: Leadership approval and executive oversight of security policy.
  • Enforcement: Access controls, monitoring, and automated policy application.
  • Employee Compliance: Daily adherence to acceptable use and data handling policies.
  • Security Awareness: Ongoing training programs and phishing simulation campaigns.
  • Ongoing Review: Periodic audits and policy updates to address emerging threats.

Kerberos Ticket-Based Authentication

▶

Kerberos is the default authentication protocol for Active Directory. It uses encrypted time-stamped tickets so plaintext passwords never traverse the network.

  • KDC (Key Distribution Center): The trusted third-party server that issues all tickets. Contains the Authentication Server (AS) and Ticket Granting Server (TGS).
  • TGT (Ticket Granting Ticket): Issued at login. Proves identity to the KDC — presented to request service tickets without re-entering credentials.
  • Service Ticket: Issued per resource. Presented directly to the target server (file share, SQL server) to gain access.

Kerberos eliminates the need to send passwords across the wire. Every ticket is time-stamped and encrypted — replay attacks are blocked because expired tickets are rejected.

Client → AS: "I'm user X, here's my hashed password"
AS → Client: TGT (encrypted with KDC secret key)
Client → TGS: "I need access to File Server, here's my TGT"
TGS → Client: Service Ticket for File Server
Client → File Server: Service Ticket → Access Granted

DoS/DDoS Attacks & OT Security

▶

Volumetric Attacks

Botnet traffic floods ISP uplinks to saturate bandwidth (Gbps–Tbps scale). Example: UDP flood, DNS amplification.

Protocol Attacks

Exhausts firewall state tables or router memory. Example: TCP SYN flood leaves half-open connections that consume state table entries.

Application Attacks

Floods web/database server CPU with heavy HTTP requests. Example: HTTP GET flood, Slowloris (holds connections open indefinitely).

DDoS Mitigation

Anycast BGP scrubbing centers absorb and filter attack traffic before it reaches origin infrastructure. Cloud rate-limiting filters drop volumetric bursts.

OT / ICS / SCADA Security:

  • Physical Safety Priority: Continuous availability and physical safety trump confidentiality — a shutdown can cause physical harm.
  • Air-Gapped Isolation: Physical or logical separation from public Internet. No direct inbound or outbound connectivity.
  • Legacy Equipment: Industrial PLCs often lack modern encryption. Strict VLAN boundaries and unidirectional gateways compensate.

Endpoint Hardening & EDR

▶

Behavioral Heuristics (EDR)

Identifies zero-day malware by monitoring process behavior — memory injection, unusual child processes — rather than static signature matching.

Automated Isolation

EDR agents instantly sever compromised endpoints from network switches upon threat detection, containing lateral spread before manual response.

Patch Management Rings

Staged OS/software update rollout: Dev → Pilot → Enterprise. Catches breaking changes before they hit production endpoints.

TPM 2.0 & BitLocker

TPM chip stores encryption keys in hardware. BitLocker uses TPM to encrypt the full OS volume — stolen drives are unreadable without the chip.

Content Filtering

▶

Web/URL Filtering

Compares requested URLs against threat intelligence databases. Blocks access to known malicious, phishing, or policy-violating sites.

DNS Filtering

Intercepts DNS resolution requests. Prevents malicious domains from resolving to IP addresses — stops the connection before a TCP session is established.

Email/Spam Filtering

Inspects message headers, attachments, and embedded links. Sandboxes suspicious attachments before delivery to user inboxes.

Threat Vectors: Malicious websites deliver infected executables (rootkits, ransomware) through phony download links, drive-by exploits, and malicious ad networks. DNS filtering is the earliest and cheapest blocking layer.

Active Directory OUs & Group Policy Objects

▶

Active Directory Organizational Units (OUs) organize users, computers, and servers into a logical hierarchy that maps to business departments.

  • Hierarchical Structure: Domain → OUs (Finance, IT, HR) → Sub-OUs → User/Computer objects.
  • RBAC: Assigns permissions based on OU membership — Finance OU users access financial shares; IT OU admins get elevated rights.
  • Inheritance: Child OUs automatically inherit GPOs applied to parent containers, reducing redundant configuration.

Group Policy Object (GPO) Enforcement:

Centralized Baselines

Automatically pushes password complexity requirements, screen lock timers, and firewall rules to all domain-joined PCs at login.

USB & Device Blocking

Disables removable storage devices enterprise-wide to prevent malware ingestion and unauthorized data exfiltration.

Automated Software Push

Silently deploys EDR agents, security patches, and approved software across thousands of endpoints without user interaction.

IKEv2 negotiates encryption keys. ESP encrypts payload; AH provides integrity. Used for Site-to-Site tunnels.

Runs over HTTPS port 443 — traverses most firewalls without special rules. Common for remote access clients (OpenVPN, Cisco AnyConnect).

Zero Trust Architecture

▶

Core Principle — Never Trust, Always Verify: Zero Trust abandons the implicit trust granted to users inside the network perimeter. Every access request is evaluated continuously, regardless of source location.

Policy Decision Engine (PDP)

Continuously evaluates user identity, device health posture, RBAC role, and request context before granting access. Access is session-level, not network-level.

Microsegmentation

Divides the network into granular security zones. A compromised host in one zone cannot move laterally to adjacent workloads without re-authenticating.

Continuous Risk Scoring

Device health, geo-location anomalies, and behavior analytics feed the PDP in real time. A suddenly anomalous device triggers step-up authentication.

Identity as the Perimeter

The verified identity of a user + device + context replaces network location as the trust boundary. VPN alone is not sufficient.

Four Core Pillars of Modern Enterprise Security

▶
01 / Layered CIA Defense

CIA Triad & Incident Response

Enforce Confidentiality, Integrity, and Availability across every layer. Utilize Incident Response loops (Prevent → Detect → Respond → Recover) to minimize breach impact.

02 / Ticketed Identity & AAA

AAA, MFA & Kerberos SSO

Centralize identity with AAA frameworks, 2+ factor MFA, and ticket-based Kerberos SSO to eliminate plaintext password transmissions across enterprise subnets.

03 / Proactive Perimeter & Endpoint

Firewalls, NIPS & EDR

Deploy stateful firewalls and inline NIPS at boundaries. Combine EDR behavioral heuristics, TPM 2.0 BitLocker encryption, and Active Directory GPOs on endpoints.

04 / Zero Trust Architecture

Never Trust, Always Verify

Abandon implicit trust. Enforce continuous PDP policy evaluations and microsegmented network zones across all access points and user identities.
